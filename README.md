# estoque_produtos
Sistema de Controle de Estoque 

Desenvolvido em Python como projeto acadêmico e de prática de programação. 

Objetivo 

Criar uma aplicação simples para controle de produtos, permitindo consultar o estoque, registrar entradas e saídas e aplicar validações básicas. 

Funcionalidades 

 Visualização dos produtos, quantidades e preços; 

 Registro de entrada de produtos; 

 Registro de saída de produtos; 

 Validação de estoque insuficiente; 

 Identificação de produtos não cadastrados; 

 Menu interativo executado pelo terminal. 

Tecnologias 

Python 3 

Listas e dicionários 

Estruturas if/elif/else 

Loops for e while 

input() e print() 

Manipulação de strings 

Formatação de valores numéricos 

Aprendizados 

Durante o desenvolvimento, consolidei conhecimentos em: 

Lógica de programação; 

Manipulação de listas e dicionários; 

Estruturas condicionais e de repetição; 

Busca e atualização de dados; 

Validação de regras de negócio; 

Entrada e tratamento básico de dados; 

Organização e documentação de código. 

O projeto também contribuiu para o desenvolvimento do raciocínio lógico e da capacidade de transformar um problema prático em uma solução funcional. 

Como executar 

É necessário ter o Python 3 instalado. 

cd estoque-produtos 

python estoque_produtos.py
